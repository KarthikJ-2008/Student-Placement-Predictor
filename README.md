## 📌 About the Project

**Student Placement Prediction** is a Machine Learning web application developed using **Python and Flask**.

The application takes important student-related inputs such as:

- 📊 CGPA
- 💼 Internships
- 💻 Projects
- 🏆 Certifications
- 🗣️ Communication Skills
- 📚 Backlogs

These values are provided to a trained Machine Learning model, which generates a placement prediction.

The project also includes a responsive and modern web interface that can be used on both **desktop and mobile devices**.

🚀 Run the Project Locally

1️⃣ Clone the Repository
git clone https://github.com/KarthikJ-2008/Student-Placement-Predictor.git

2️⃣ Open the Project
cd student-placement-prediction

3️⃣ Create a Virtual Environment
python -m venv myenv

4️⃣ Activate the Environment
Windows:
myenv\Scripts\activate

5️⃣ Install Required Libraries
pip install -r requirements.txt

6️⃣ Run Flask
python app.py

7️⃣ Open in Browser
http://127.0.0.1:5000/
